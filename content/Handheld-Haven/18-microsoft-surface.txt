MICROSOFT SURFACE

Microsoft's Surface tablets: the ARM Surface RT and Surface 2, the Intel Surface 3, the Surface Pro line through the 2025 Pro 12-inch, the Surface Go line, and a note on the Android Surface Duo. These are tablets with keyboard covers, not gaming handhelds, but they are the most common small Windows computers.

ENTRY: Surface (first generation), later called Surface RT
Maker: Microsoft
Released: Announced June 2012; released October 26, 2012; discontinued July 18, 2013 (Wikipedia).
Launch price: US$499 and up (The Verge, 2012). Cut 30 percent to US$350 in July 2013 (Wikipedia).

WHAT IT CAN DO
Microsoft's first in-house PC: an ARM tablet running Windows RT, which looks like Windows 8 but cannot install traditional desktop programs.

HARDWARE
Processor: Nvidia Tegra 3, 1.3 GHz (quad-core ARM).
Memory: 2 GB DDR3, soldered.
Graphics: Nvidia Tegra 3 integrated (GeForce ULP).
Storage: 32 or 64 GB eMMC; microSDXC (under the kickstand).
Display: 10.6-inch 1366 by 768.
Battery: 31.5 Wh; 24 W charger. The Verge: about eight hours claimed, a full day of heavy use observed.
Weight and size: 1.5 pounds (680 g); 10.81 by 6.77 by 0.37 inches.
Operating system: Windows RT, upgradable to Windows RT 8.1.
Wi-Fi and network: Wi-Fi 802.11a/b/g/n.
Bluetooth: Bluetooth 4.0.
Cellular: None.
Ports and expansion (USB4, Thunderbolt, eGPU, video out, microSD, docking): USB 2.0, micro HDMI, 3.5 mm headphone jack, microSDXC, cover connector.
Other hardware (fingerprint or Windows Hello, cameras, speakers, headphone jack, haptics, gyro): Two 720p cameras, two microphones, stereo speakers that sometimes distorted (The Verge); accelerometer, gyroscope, magnetometer, ambient light sensor.

CONTROLS AND BUTTON LAYOUT
No game controls. Power and volume buttons on the edges; detachable Type Cover keyboard sold separately (except where noted); kickstand.

HOW IT FEELS
The Verge: a magnesium (VaporMg) slab that feels like thin, stiff aluminium, with edges that taper back from the glass. A full-width kickstand flips out of the back; its metal edges are extremely sharp and scratched wooden surfaces. At nearly 11 inches wide it is awkward to hold in landscape for long and "laughably tall" in portrait. A capacitive Windows button sits centered below the screen. Touch Cover keyboards have no moving keys; Type Covers have real keys.

BLIND USABILITY
With a Type Cover or Signature Keyboard attached, Windows key+Ctrl+Enter starts Narrator like on any laptop, and NVDA or JAWS install normally (except on Windows RT, see below). Without a keyboard, Microsoft documents Windows button+Volume Up for touch devices; this works only on models with a hardware or capacitive Windows button. Narrator touch gestures (flick left or right to move, double-tap to activate, three-finger swipes to tab) let you use the tablet by touch alone. Accessibility of Surface out-of-box setup has not been specifically reviewed in sources found; Windows setup itself offers Narrator. Surfaces have no game controls, so for games you add a Bluetooth or USB controller or keyboard. This model has a Windows button below the screen (capacitive on the Surface RT, per The Verge), so Windows button+Volume Up can start Narrator without a keyboard (behavior on this exact model not tested in sources; UNCERTAIN). Windows RT models (Surface RT and Surface 2) do not allow ordinary desktop programs except Microsoft Office and Internet Explorer (The Verge), so NVDA and JAWS cannot be installed; Narrator is the only screen reader. Microsoft provided security updates for Surface 2 until January 2023 (Wikipedia). Not recommended for a blind buyer today.

GAME COMPATIBILITY
Performance tier: very low; Windows Store apps only. Audio games for desktop Windows will not install.

UNCERTAIN
None.
