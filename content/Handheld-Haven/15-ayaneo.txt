ENTRY: AYANEO (original, 2021) and AYANEO 2021 Pro
Maker: AYANEO (Anyun Intelligent Technology, Hong Kong; founded 2020 by Arthur Zhang)
Released: 2021, crowdfunded on Indiegogo (Wikipedia).
Launch price: Reported Indiegogo price US$789 for the 4500U model (search summary of AYANEO's own price article, UNCERTAIN).

WHAT IT CAN DO
AYANEO's first Windows handheld, launched before the Steam Deck. Reviewers called performance acceptable for less demanding games, for a niche crowd (Wikipedia).

HARDWARE
Processor: AMD Ryzen 5 4500U (6 cores/6 threads, Zen 2); the Pro used a faster chip (model not documented here).
Memory: 16 GB.
Graphics: AMD Radeon integrated (Vega).
Storage: 512 GB or 1 TB SSD.
Display: 7-inch 1280 by 800 touchscreen.
Battery: not documented
Weight and size: About 1.5 pounds (Liliputing's ONEXPLAYER review comparison).
Operating system: Windows 10 (at launch; UNCERTAIN).
Wi-Fi and network: not documented
Bluetooth: not documented
Cellular: not documented
Ports and expansion (USB4, Thunderbolt, eGPU, video out, microSD, docking): not documented
Other hardware (fingerprint or Windows Hello, cameras, speakers, headphone jack, haptics, gyro): Linear analog triggers (DROIX).

CONTROLS AND BUTTON LAYOUT
Standard handheld layout with linear triggers.

HOW IT FEELS
About 1.5 pounds. DROIX describes the original as slightly unwieldy, which the Next later improved. THIN ENTRY.

BLIND USABILITY
No keyboard is built in, so the standard Narrator shortcut (Windows key+Ctrl+Enter) needs a USB or Bluetooth keyboard. Microsoft's alternative for touch devices, Windows button+Volume Up, needs a hardware Windows button, which this device does not list in its controls, so it should not be relied on (UNCERTAIN whether the maker maps a combination to it). Can I Play That's review of the ROG Xbox Ally X found Narrator is available right away during Windows setup, but setup only mentions keyboard combinations, not controller buttons, and blind users may struggle to turn it on with the small on-screen icons. The same applies to any Windows 11 handheld. Plan to plug in a keyboard for first setup. Once Windows is set up, turn on Start Narrator before sign-in (or install NVDA), and remap a spare back button to a keyboard shortcut if the maker's software allows it. AYASpace (AYANEO's launcher) accessibility with screen readers is not documented. AYANEO devices are crowdfunded by a small company; warranty and repair support are weaker than ASUS or Lenovo (general reporting, Liliputing commenters).

GAME COMPATIBILITY
Performance tier: low-mid.

THIN ENTRY.

ENTRY: AYANEO Flip KB and Flip DS
Maker: AYANEO
Released: Early 2024; 7840U version shipping from mid-March, 8840U from end of April (AYANEO).
Launch price: Early bird from US$699 (Flip KB) and US$739 (Flip DS) (AYANEO).

WHAT IT CAN DO
Clamshell handhelds: the KB has a full RGB backlit keyboard between the grips; the DS has a second screen there.

HARDWARE
Processor: AMD Ryzen 7 7840U or 8840U.
Memory: not documented
Graphics: AMD Radeon 780M.
Storage: not documented
Display: not documented
Battery: not documented
Weight and size: not documented
Operating system: Windows 11.
Wi-Fi and network: not documented
Bluetooth: not documented
Cellular: not documented
Ports and expansion (USB4, Thunderbolt, eGPU, video out, microSD, docking): not documented
Other hardware (fingerprint or Windows Hello, cameras, speakers, headphone jack, haptics, gyro): Optical finger mouse; independent Home button; hinge with three click-stop angles at 120, 150 and 180 degrees, then locks; rubber pads between screen and base (AYANEO).

CONTROLS AND BUTTON LAYOUT
Recessed joystick, D-pad, ABXY and shoulder buttons with metal dome switches ("crisp and light feedback"), hall-effect sticks and triggers; Fn row for F-keys (AYANEO).

HOW IT FEELS
AYANEO says the body has rounded corners and interchangeable grip pieces in two textures: an anti-slip "Star Diamond" texture and a smooth anti-sweat "Galaxy" texture. The hinge clicks at three angles, which is easy to feel.

BLIND USABILITY
No keyboard is built in, so the standard Narrator shortcut (Windows key+Ctrl+Enter) needs a USB or Bluetooth keyboard. Microsoft's alternative for touch devices, Windows button+Volume Up, needs a hardware Windows button, which this device does not list in its controls, so it should not be relied on (UNCERTAIN whether the maker maps a combination to it). Can I Play That's review of the ROG Xbox Ally X found Narrator is available right away during Windows setup, but setup only mentions keyboard combinations, not controller buttons, and blind users may struggle to turn it on with the small on-screen icons. The same applies to any Windows 11 handheld. Plan to plug in a keyboard for first setup. Once Windows is set up, turn on Start Narrator before sign-in (or install NVDA), and remap a spare back button to a keyboard shortcut if the maker's software allows it. AYASpace (AYANEO's launcher) accessibility with screen readers is not documented. AYANEO devices are crowdfunded by a small company; warranty and repair support are weaker than ASUS or Lenovo (general reporting, Liliputing commenters). The Flip KB's built-in keyboard with an F-key area makes screen reader commands reachable without an external keyboard, a real plus for blind buyers.

Performance tier: upper-mid.

ENTRY: AYANEO 3

Wi-Fi and network: not documented

Cellular: not documented
