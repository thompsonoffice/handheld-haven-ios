ENTRY: ONEXPLAYER (original, Intel)
Maker: One Netbook (ONEXPLAYER brand), China
Released: Indiegogo 2021; shipping to backers from June 2021 (Liliputing).
Launch price: From US$819 on Indiegogo, US$1,059 and up after the campaign (Liliputing, 2021).

WHAT IT CAN DO
A big 8.4-inch Windows handheld with console-quality controls and Thunderbolt-class USB4 ports for desktop docking.

HARDWARE
Processor: Intel Core i7-1165G7 (Tiger Lake, four cores/eight threads); runs at 20 W by default, with a Turbo button raising it to 28 W (Liliputing).
Memory: not documented
Graphics: Intel Iris Xe (integrated).
Storage: not documented
Display: 8.4-inch touchscreen.
Battery: not documented
Weight and size: About 1.8 pounds; about 11 by 5 by 1 inches.
Operating system: Windows 10 (at launch).
Wi-Fi and network: not documented
Bluetooth: not documented
Cellular: not documented
Ports and expansion (USB4, Thunderbolt, eGPU, video out, microSD, docking): Two USB4 ports; external monitor, mouse and keyboard supported.
Other hardware (fingerprint or Windows Hello, cameras, speakers, headphone jack, haptics, gyro): Built-in adjustable kickstand. Optional keyboard cover US$40 (crowdfunding) or US$80 (retail).

CONTROLS AND BUTTON LAYOUT
Xbox-style split: D-pad and left stick on the left, lettered buttons and right stick on the right, four shoulder buttons including two linear pressure-sensitive triggers. Special keys, clockwise from bottom left: Home, Back/Select, Start, Keyboard, Turbo (Liliputing).

HOW IT FEELS
Liliputing: plastic, but "there's no give when you squeeze"; the controllers feel like an Xbox controller split in two around the screen. At about 1.8 pounds, twice a Switch, it is heavy to hold for long; resting the bottom on your lap works well.

BLIND USABILITY
No keyboard is built in, so the standard Narrator shortcut (Windows key+Ctrl+Enter) needs a USB or Bluetooth keyboard. Microsoft's alternative for touch devices, Windows button+Volume Up, needs a hardware Windows button, which this device does not list in its controls, so it should not be relied on (UNCERTAIN whether the maker maps a combination to it). Can I Play That's review of the ROG Xbox Ally X found Narrator is available right away during Windows setup, but setup only mentions keyboard combinations, not controller buttons, and blind users may struggle to turn it on with the small on-screen icons. The same applies to any Windows 11 handheld. Plan to plug in a keyboard for first setup. Once Windows is set up, turn on Start Narrator before sign-in (or install NVDA), and remap a spare back button to a keyboard shortcut if the maker's software allows it. OneXPlayer's software accessibility is not documented. The original ONEXPLAYER had a dedicated keyboard button that pops up the Windows on-screen keyboard and, held down, switches to mouse mode (Liliputing); with Narrator, the touch keyboard is usable by touch exploration but slow.

GAME COMPATIBILITY
Performance tier: mid for 2021.

UNCERTAIN
Memory and storage options not documented here.
